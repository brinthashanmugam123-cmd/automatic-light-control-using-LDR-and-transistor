                            **Automatic Light Control using LDR**

**OBJECTIVE :**  
        This project demonstrates an automatic light control system using an LDR (Light Dependent Resistor). The circuit automatically switches the LED OFF during bright conditions and ON during dark conditions, helping reduce unnecessary power consumption. 

### **COMPONENTS USED :**

* LDR (Light Dependent Resistor)  
* LED  
* Transistor  
* Resistor  
* 9V Battery  
* Breadboard  
* Connecting Wires

### **Simulation & Hardware :**

* The circuit was first tested using **Tinkercad simulation** and then implemented practically on a **breadboard** using the required electronic components.


**Project Outcome :**

* This project provides a simple and effective solution for automatic lighting by switching the LED ON in darkness and OFF in daylight.
